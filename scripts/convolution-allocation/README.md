# Convolution cold-allocation regression gate

The current exact implementation allocates about 22 MB on its first convolution call, versus 5 MB published. This fixed protocol tests its replacement against both artifacts. Only the published baseline determines the regression verdict; the unreleased implementation remains an explicit attribution control.

Freeze source, protocol and workflow before dispatch. Two hosts for each architecture/JDK configuration run 32 rotated three-arm fresh-process cohorts. No retries, exclusions or optional stopping. Every process retains its command, output, artifact hashes and numerical checks. Eight-cohort checkpoints are uploaded before the next block. The first-call counter includes VectorUtil, Panama and helper initialization, unlike the earlier diagnostic. Warm measurements use changing inputs and retain the entire recurrent history. The candidate must match independent scalar/FMA output and history bits both cold and warm.

Cold allocation must be no larger than published in every matched pair and its paired upper confidence bound must be at most one. Warm allocation must not increase beyond eight bytes per call of probe noise. Warm latency uses the existing upper ratio limit one and confidence-width limit 0.02. The estimator weights hosts equally and resamples hosts then matched process pairs, preserving host heterogeneity. Actual CPU models are retained. No passing claim follows from an incomplete cohort or a precision failure. Cold latency is recorded; the existing separate whole-model startup gate remains required.

The standalone helper additionally enumerates all 580,911,106 signed inputs in the certified interval on each host; boundary tests cover requested widths and FMA settings. JDK/hardware-specific results remain distinct. Supported-host component success does not substitute for real-model correctness, quality, or resource gates.

All three artifacts are built and core tests executed with pinned Temurin25.0.3 and explicit Gradle toolchain path. The selected measurement JDK is installed afterward; compiled-helper proofs and paired actual-JAR operations execute on that JDK. Artifact hashes must match across all jobs. Aliasing and public nonfinite regressions run in core tests at default mode; disjoint persistent-history convolution additionally runs in12 fresh width/FMA/scalar configurations. Requested SIMD ceilings do not imply unavailable hardware widths were executed.
